# AI Focus v0.1.0 — Windows Preview

First public Windows build of AI Focus, a local-first AI session dashboard.

## Included
- Windows x64 portable application (self-contained; no .NET installation required).
- Chrome/Edge browser extension in the `extension/` folder.
- Browser Native Messaging bridge included alongside the main EXE.
- Local Claude Code and Codex conversation previews, session status, focus shortcuts, notifications and floating widget.
- Chinese and English user interfaces and documentation.

## Install / 安装
1. Download and extract `AiFocus-v0.1.0-win-x64.zip`.
2. Run `AiFocus.exe`. Use **Alt + Q** to open the panel.
3. Optional: Chrome or Edge -> Extensions -> Developer mode -> **Load unpacked** -> select the extracted `extension/` folder.
4. Keep AI Focus running. The app automatically registers the local browser bridge for the current user.

Notes: Windows 10 (1809+) / Windows 11 x64 only. Unsigned preview build: Windows SmartScreen may show a warning. Do not ignore warnings for downloads from other sources.

## Privacy
AI Focus runs locally. It reads window metadata and selected local AI transcripts; the optional browser extension can read supported AI website conversations when requested for preview. See README for details.

macOS support is planned, but not included in this release.
