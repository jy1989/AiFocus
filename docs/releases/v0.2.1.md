# AI Focus v0.2.1 — Windows Preview

A new look, and a floating widget that stays out of your way.

## Changed
- New app and tray icon.
- New blue colour scheme across the panel and widget, matching the icon.
- The floating widget is now a small badge: a status dot and the number of sessions waiting for you, or the app icon when nothing needs you.
- The widget opens only after the mouse rests on it, and always opens towards the middle of the screen.
- The widget's default position moved from the top-right to the bottom-right corner, away from close buttons and tab bars. If you moved the widget before, it keeps your position.

## Install / 安装
1. Install the [.NET Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) 10 (x64); version 9 also works.
2. Download and extract `AiFocus-v0.2.1-win-x64.zip`.
3. Run `AiFocus.exe`. Use **Alt + Q** to open the panel.
4. Optional: Chrome or Edge -> Extensions -> Developer mode -> **Load unpacked** -> select the extracted `extension/` folder.
5. Keep AI Focus running. The app automatically registers the local browser bridge for the current user.

Upgrading from v0.2.0: exit AI Focus and replace `AiFocus.exe`. The browser extension and bridge are unchanged.

The tray icon may start in the `^` overflow area of the taskbar; drag it onto the taskbar to keep it visible.

Notes: Windows 10 (1809+) / Windows 11 x64 only. Unsigned preview build: Windows SmartScreen may show a warning. Do not ignore warnings for downloads from other sources.

## Privacy
AI Focus runs locally. It reads window metadata and local Claude Code and Codex transcripts, and the optional browser extension reports AI tab titles, URLs and generation state. See README for details.

macOS support is planned, but not included in this release.
