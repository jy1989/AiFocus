# AI Focus v0.2.0 — Windows Preview

A much smaller and simpler AI Focus: the download drops from about 104 MB to about 6 MB.

## Changed
- The .NET runtime is no longer bundled. Install the [.NET Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) 10 (x64) first; version 9 also works. If it is missing, AI Focus shows a dialog with a download link.
- The browser bridge no longer carries its own copy of the runtime either.

## Removed
- The Console view (full-screen cards with live window previews).
- The Chat view (`Tab`) and Markdown conversation preview. Cards still show the AI's latest reply in one line.
- The browser extension no longer reads conversations from AI websites.

## Install / 安装
1. Install the [.NET Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) 10 (x64).
2. Download and extract `AiFocus-v0.2.0-win-x64.zip`.
3. Run `AiFocus.exe`. Use **Alt + Q** to open the panel.
4. Optional: Chrome or Edge -> Extensions -> Developer mode -> **Load unpacked** -> select the extracted `extension/` folder.
5. Keep AI Focus running. The app automatically registers the local browser bridge for the current user.

Upgrading from v0.1.0: replace both EXE files, then click **Reload** on the extension in `chrome://extensions`.

Notes: Windows 10 (1809+) / Windows 11 x64 only. Unsigned preview build: Windows SmartScreen may show a warning. Do not ignore warnings for downloads from other sources.

## Privacy
AI Focus runs locally. It reads window metadata and local Claude Code and Codex transcripts, and the optional browser extension reports AI tab titles, URLs and generation state. See README for details.

macOS support is planned, but not included in this release.
